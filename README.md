# QR Toolkit

A desktop application built using Python that lets you generate and decode QR codes.

## Features

- Generate QR Codes from text or URLs
- decode QR codes by uploading an image
- save generated QR codes as an image
- preview generated QR Codes

## Instructions

Download the latest release and open QRToolkit.exe

If Windows blocks the executable:

1. Open Windows Security.
2. Go to App & browser control.
3. Open Smart App Control settings.
4. Turn it off.
5. Launch the application again.
